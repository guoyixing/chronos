# 插件系统

Chronos支持通过插件系统扩展功能。插件可以在Chronos生命周期的不同阶段执行自定义逻辑，甚至注册自定义组件。

## 基础用法

在创建Chronos实例时，通过第三个参数传入插件配置：

```javascript
import { Chronos } from 'other-chronos';

// 定义插件
const myPlugin = {
    name: 'my-plugin',
    version: '1.0.0',
    onInstall(ctx) {
        ctx.log('info', '插件已安装');
    },
    onAfterStart(ctx) {
        ctx.log('info', 'Chronos已启动');
    }
};

// 创建Chronos实例并传入插件
const chronos = new Chronos(divElement, data, {
    plugins: [myPlugin]
});
```

## 插件接口

| 属性名 | 中文名 | 类型 | 是否必要 | 备注 |
| ------ | ------ | ---- | --- | --------- |
| name | 插件名称 | string | 必要 | 必须唯一 |
| version | 插件版本 | string | 非必要 | 版本号 |
| dependencies | 依赖插件 | string[] | 非必要 | 依赖的其他插件名称列表 |
| onInstall | 安装钩子 | function | 非必要 | Context创建后，组件绑定前调用 |
| onBeforeInit | 初始化前钩子 | function | 非必要 | 所有组件init()调用前 |
| onAfterInit | 初始化后钩子 | function | 非必要 | 所有组件init()调用后 |
| onAfterStart | 启动后钩子 | function | 非必要 | 所有组件start()调用后 |
| onDestroy | 销毁钩子 | function | 非必要 | destroy()时调用 |

## 生命周期钩子

插件的生命周期钩子按以下顺序被调用：

```
1. onInstall     - Context创建后，组件绑定前
2. onBeforeInit  - 所有组件绑定后，init()调用前
3. onAfterInit   - 所有组件init()调用后
4. onAfterStart  - 所有组件start()调用后（渲染完成）
5. onDestroy     - Chronos.destroy()时调用
```

样例

```javascript
const lifecyclePlugin = {
    name: 'lifecycle-demo',
    
    onInstall(ctx) {
        // 在这里可以注册自定义组件
        console.log('1. 插件安装');
    },
    
    onBeforeInit(ctx) {
        // 组件初始化前的准备工作
        console.log('2. 初始化前');
    },
    
    onAfterInit(ctx) {
        // 组件已初始化，但尚未渲染
        console.log('3. 初始化后');
    },
    
    onAfterStart(ctx) {
        // 组件已渲染完成
        console.log('4. 启动完成');
    },
    
    onDestroy(ctx) {
        // 清理插件资源
        console.log('5. 销毁');
    }
};
```

## 插件上下文 (PluginContext)

每个生命周期钩子都会接收一个`PluginContext`对象，提供以下API：

| 方法/属性 | 说明 | 参数 |
| --------- | ---- | ---- |
| context | 只读的Chronos上下文对象 | - |
| registerComponent | 注册自定义组件 | ComponentRegistration |
| on | 订阅事件 | event: symbol, handler: function |
| emit | 发布事件 | event: symbol, data?: unknown |
| getPlugin | 获取其他插件实例 | name: string |
| log | 日志输出 | level: 'debug'\|'info'\|'warn'\|'error', message: string |

样例

```javascript
const eventPlugin = {
    name: 'event-demo',
    
    onAfterStart(ctx) {
        // 订阅事件
        ctx.on(Symbol.for('custom-event'), (data) => {
            console.log('收到事件:', data);
        });
        
        // 发布事件
        ctx.emit(Symbol.for('custom-event'), { message: 'Hello' });
        
        // 日志输出
        ctx.log('info', '插件已启动');
    }
};
```

## 插件依赖

插件可以声明依赖其他插件。Chronos会自动按依赖顺序安装插件：

```javascript
const basePlugin = {
    name: 'base-plugin',
    version: '1.0.0',
    onInstall(ctx) {
        // 基础功能
    }
};

const extendPlugin = {
    name: 'extend-plugin',
    version: '1.0.0',
    dependencies: ['base-plugin'],  // 声明依赖
    onInstall(ctx) {
        // 可以安全地访问base-plugin
        const base = ctx.getPlugin('base-plugin');
        console.log('基础插件版本:', base.version);
    }
};

// 顺序无关，Chronos会自动排序
const chronos = new Chronos(div, data, {
    plugins: [extendPlugin, basePlugin]  // 会自动先安装basePlugin
});
```

### 依赖规则

1. **依赖必须存在**：如果插件声明的依赖不在插件列表中，会抛出错误
2. **循环依赖检测**：如果存在循环依赖（A依赖B，B依赖A），会抛出错误
3. **自动排序**：Chronos使用拓扑排序确保依赖先于依赖者安装

## 错误隔离

插件中的错误不会影响Chronos的正常运行。如果某个插件的钩子抛出错误，Chronos会：

1. 在控制台记录错误信息
2. 继续执行其他插件的钩子
3. 继续正常的初始化/启动流程

```javascript
const buggyPlugin = {
    name: 'buggy-plugin',
    onInstall(ctx) {
        throw new Error('插件出错了！');
        // 错误会被捕获并记录，不影响其他插件
    }
};

const normalPlugin = {
    name: 'normal-plugin',
    onInstall(ctx) {
        ctx.log('info', '正常运行');
        // 这个插件会正常执行
    }
};
```

## 完整样例

```javascript
import { Chronos } from 'other-chronos';

// 主题插件 - 动态修改样式
const themePlugin = {
    name: 'theme-plugin',
    version: '1.0.0',
    
    onAfterStart(ctx) {
        // 访问Context进行自定义操作
        const context = ctx.context;
        ctx.log('info', `Chronos宽度: ${context.drawContext.width}`);
    },
    
    onDestroy(ctx) {
        ctx.log('info', '主题插件已清理');
    }
};

// 日志插件 - 记录所有生命周期事件
const loggerPlugin = {
    name: 'logger-plugin',
    version: '1.0.0',
    
    onInstall(ctx) {
        ctx.log('debug', '[Logger] Chronos安装中...');
    },
    
    onBeforeInit(ctx) {
        ctx.log('debug', '[Logger] 准备初始化...');
    },
    
    onAfterInit(ctx) {
        ctx.log('debug', '[Logger] 初始化完成');
    },
    
    onAfterStart(ctx) {
        ctx.log('info', '[Logger] Chronos启动完成');
    },
    
    onDestroy(ctx) {
        ctx.log('debug', '[Logger] Chronos销毁');
    }
};

// 创建Chronos实例
const chronos = new Chronos(
    document.getElementById('chronos'),
    {
        timeline: { initTime: '2024-01-01 00:00:00' }
    },
    {
        plugins: [themePlugin, loggerPlugin]
    }
);

// 销毁时会触发onDestroy钩子
// chronos.destroy();
```

## TypeScript支持

如果使用TypeScript，可以导入类型定义：

```typescript
import { Chronos } from 'other-chronos';
import type { ChronosPlugin, PluginContext } from 'other-chronos';

const myPlugin: ChronosPlugin = {
    name: 'typed-plugin',
    version: '1.0.0',
    
    onInstall(ctx: PluginContext): void {
        ctx.log('info', '类型安全的插件');
    }
};
```
